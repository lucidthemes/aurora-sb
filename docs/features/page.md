# Page

## Overview

The page feature is used to fetch the single page

## Source

- [View on GitHub](https://github.com/lucidthemes/aurora-sb/tree/main/src/features/page)

## Responsibilities

- Fetch the page from Supabase

## Structure

The feature contains the following files:

- **loading** - the loading component when fetching the page
- **getPage** - fetches the page from Supabase
- **page.schema** - the schema used for the page
- **useSinglePage** - used to fetch the page from Supabase
