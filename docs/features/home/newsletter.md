# Home - newsletter

## Overview

The home newsletter feature displays a newsletter form

## Source

- [View on GitHub](https://github.com/lucidthemes/aurora-sb/tree/main/src/features/home/newsletter)

## Responsibilities

- Display a newsletter form
- Allow a user to enter their email address and sign up for the newsletter
- Show a success message if sign up was successful
- Show an error message if there was an error signing up the user

## Structure

The feature contains the following files:

- **newsletter** - wraps around the newsletter form component with a title and text
