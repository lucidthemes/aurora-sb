# Search form

## Overview

The search form feature is used to output a search form

## Source

- [View on GitHub](https://github.com/lucidthemes/aurora-sb/tree/main/src/features/searchForm)

## Responsibilities

- Display the search form fields
- Navigate to the search page on form submission

## Structure

The feature contains the following files:

- **searchForm** - used to display the search form
- **search.schema** - the schema used for the form field
- **useSearchForm** - the form hook using React Hook Form
