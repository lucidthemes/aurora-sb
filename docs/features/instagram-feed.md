# Instagram feed

## Overview

The Instagram feed feature is used to output an Instagram feed

## Source

- [View on GitHub](https://github.com/lucidthemes/aurora-sb/tree/main/src/features/instagramFeed)

## Responsibilities

- Display the Instagram feed images

## Structure

The feature contains the following files:

- **components** - the loading component when fetching the Instagram feed
- **instagramFeed** - used to display the Instagram feed
- **getInstagramFeed** - fetches the Instagram feed and media from Supabase
- **instagram.schema** - used for the Instagram feed and media
- **useInstagramFeed** - used to fetch the Instagram feed and media from Supabase
