# Star rating

## Overview

The product star rating feature is used to output the star rating

## Source

- [View on GitHub](https://github.com/lucidthemes/aurora-sb/tree/main/src/features/product/starRating)

## Responsibilities

- Display a series of stars with a certain number filled to indicate the star rating

## Structure

The feature contains the following files:

- **components** - used to display the full, half, and empty star components
- **starRating** - used to display the star rating
